## 📱 Overview

BonaPay is a complete fintech platform offering secure digital banking services including money transfers, bill payments, virtual cards, savings, and investment products. This repository contains the **admin web portal** for managing the platform, while regular users access services through the mobile app.

### Key Features

- 🔐 **Secure Authentication** - 2FA, biometric login, session management
- 💸 **Money Transfers** - Send money to any bank account
- 💡 **Bill Payments** - Electricity, airtime, data, cable TV, betting
- 💳 **Virtual Cards** - Create and manage virtual cards for online payments
- 📈 **Savings & Investments** - Fixed deposits, target savings, investment plans
- 👑 **Admin Dashboard** - User management, KYC verification, fraud monitoring
- 🎁 **Loyalty Points** - Rewards system with redeemable points
- 📊 **Analytics** - Spending insights, budget planning, transaction reports

## 🚀 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** TailwindCSS + shadcn/ui
- **Authentication:** Supabase Auth + 2FA
- **Database:** Supabase PostgreSQL
- **State Management:** React Hooks
- **Forms:** React Hook Form + Zod
- **Charts:** Recharts
- **PDF Generation:** jsPDF
- **Animations:** Framer Motion

## 📋 Prerequisites

- Node.js 18.17 or later
- npm / yarn / pnpm / bun
- Supabase account (free tier works)
- Git
